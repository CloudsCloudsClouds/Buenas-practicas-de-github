# EyePilot

Proyecto de control de silla de ruedas inalámbrica, desarrollado como aplicación Android con Kotlin.

## Requisitos

- Android Studio con JDK 17
- Android SDK (API según `app/build.gradle.kts`)

## Compilación

```bash
./gradlew assembleDebug
```

## Instalación

Genera el APK en `app/build/outputs/apk/debug/` e instálalo en el dispositivo:

```bash
./gradlew installDebug
```
